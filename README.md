# 校园二手交易系统

基于 Java Web 的前后端分离校园二手交易系统，面向毕业设计实现与答辩展示。

## 当前基线

- 后端：Java 17、Spring Boot、Spring MVC、MyBatis、Maven
- 前端：Vue 3、Vite、Vue Router、Axios、Element Plus
- 数据库：MySQL 8.0
- 认证：JWT；权限：普通用户 / 管理员
- 交付：完整源码、数据库脚本、启动说明、毕业设计报告素材

## MVP 功能

- 用户注册、登录、个人资料和密码修改
- 商品发布、编辑、上下架、图片、分类、关键字搜索、分页筛选
- 商品详情、收藏、留言/评论、举报
- 购买意向订单：下单、确认、取消、完成；不接真实支付
- 管理员：用户、分类、商品、举报、公告、订单和数据概览

## 运行目标

当前源码后端默认 `18080`，前端默认 `15173`，使用 `http://127.0.0.1:15173` 访问。在 `server` 目录运行 `mvn spring-boot:run`，在 `web` 目录运行 `npm run dev`。前端固定代理到 `127.0.0.1:18080`，端口被占用时会直接报错，避免与图书馆等项目的 8080/5173 端口混用。上传图片保存到后端本地 `uploads/`。

## 当前演示数据与分页

当前默认配置使用 H2 内存数据库。启动时加载基础案例与 `server/src/main/resources/pagination-data.sql`，包含 78 件商品、36 个账号、33 条订单、30 条求购、40 条留言和 31 条举报；重启会恢复演示数据。初始化脚本检查导入标记，避免在同一数据库重复导入。

`student / 123456` 可查看 22 件发布、25 件收藏、28 条订单、18 条可见求购、38 条咨询。新增演示用户为 `demo1` 至 `demo24`，密码均为 `123456`。管理员为 `admin / admin123`。

所有列表接口使用数据库分页，查询参数为 `page`（从 1 开始）和 `size`（1 至 100，默认 9）。响应的 `data` 为 `{records,total,page,size}`。商品的关键词、分类、成色、价格和排序，及订单、求购、留言、举报的状态筛选，均在数据库分页之前执行。用户端列表、商品留言弹窗、管理端六个列表和概览商品列表均有分页控件。

验证：后端运行 `mvn test`，前端运行 `npm run build`。分页测试遍历 13 个列表接口，检查总数、跨页重复、最后一页、空结果、筛选排序与无效参数。

登录注册回归：安装 Playwright 的环境可运行 `node scripts/check_auth_ui.cjs`（可在第二个参数传入现有 Playwright 模块路径）。脚本访问当前源码的独立端口，实际注册测试账号、退出后重新登录，再验证管理员后台；会在演示数据库新增一个测试用户。历史交付包是独立快照，不会随当前源码的端口配置自动更新。

## 商品图片与页面轮播

发布和编辑商品支持选择本地 JPG、PNG、WEBP 图片，单张最大 5MB，可预览、移除并重新选择。前端调用 `POST /api/uploads/image` 上传文件；后端检查账号、大小和图片内容，生成随机文件名并保存到 `server/uploads/`，商品记录保存返回的 `/uploads/...` 地址。开发服务器已代理上传图片访问。上传文件在重启后保留；当前 H2 内存数据库中的用户商品记录仍会在重启后重置。

78 件演示商品分别对应 `web/public/images/goods/001.webp` 至 `078.webp`。商品图片保存为本地 WebP，书籍保留完整书封，其他商品展示对应物品，不再按分类共用一张图。初始化与图片刷新脚本都使用这些本地路径；刷新仅匹配案例的 ID 和标题，不覆盖同名用户商品。

轮播图片独立保存在 `web/public/images/banners/`，与商品图不共用文件。六个用户页面、七个管理页面以及管理员浏览集市页面各有三张专属图片，共 42 张；页面内、页面间均不重复。默认每 3.5 秒自动切换，悬停与焦点不会停止播放，手动暂停只影响当前页面，切换页面后恢复自动播放。后台标签页暂停，重新显示时恢复；减少动态效果的系统偏好仅关闭过渡动画。

图片来源和文件校验信息保存在 `web/public/images/manifest.json`。如需重新准备案例图片，可安装 Pillow 后运行 `python scripts/prepare_demo_images.py`；日常启动和浏览不需要下载外部图片。

轮播素材单独准备：`python scripts/prepare_banner_images.py`，已完成且来源未改变的图片会复用本地缓存。浏览器回归脚本为 `scripts/check_banner_ui.cjs`，可使用已安装的 Playwright 运行；它逐页验证 14 个页面的自动切换、悬停/焦点后播放、手动暂停恢复、页面切换恢复，以及 42 个图片地址互不重复。
