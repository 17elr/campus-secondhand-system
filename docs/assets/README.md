# 仓库展示素材

- `cover.svg`：沿用页面的“拾”字标志、森林绿和米白色绘制的仓库封面，无远程字体或图片依赖。
- `market.webp`、`mobile.webp`、`admin.webp`、`notifications.webp`：2026-10-24 从实际运行页面采集并压缩的展示截图。
- `showcase.webp`：桌面与手机截图的展示合成图，只增加画框与背景，没有更改页面内容。

本目录用于仓库展示。原验收截图继续保存在 `docs/screenshots/`；页面中的商品与轮播素材来源见 [原始清单](../../web/public/images/manifest.json)。
