# 拾光集市 · 校园二手交易系统

项目类型：原毕业设计基础上的个人改造，2026-10-24。

技术栈：Java17、Spring Boot3.5、MyBatis、MySQL8、Redis / Spring Session、Spring Cloud2025、Gateway MVC、OpenFeign、Vue3、Element Plus、Fetch、Docker Compose。

- 将原演示身份头迁移为Redis共享Session与CSRF校验，以用户ID限制商品、意向和咨询归属；通过authVersion使改密/停用/角色变更后的旧会话失效。
- 设计购买意向状态机，使用MySQL事务、固定行锁顺序、活动意向唯一约束和请求幂等键，保证订单、商品预留及通知Outbox一并提交或回滚。
- 保持商品和订单在同一交易服务，通过Gateway MVC提供统一入口，使用OpenFeign调用独立站内通知服务；持久化Outbox租约、重试和失败补投处理通知故障。
- 保留13个数据库分页列表、收藏、咨询、求购审核和后台管理，迁移原生Fetch并补齐真实登录恢复、交易确认和通知交互。

验证细节见[实际验证记录](VALIDATION.md)。只能引用其中真实通过的检查；并发一致性验证不代表生产压测。未实现JWT、真实支付、物流、邮件短信、WebSocket、分类管理或公告模块，不填写虚构用户规模、历史开发日期或性能提升。
