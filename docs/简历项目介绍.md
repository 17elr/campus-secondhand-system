# 拾光集市 校园二手交易系统

项目类型：毕业设计，前后端分离 Web 应用。

技术栈：Java 17、Spring Boot、Spring MVC、MyBatis、Vue 3、Element Plus、Axios、Vite、H2、Maven。

项目简介：面向校园闲置物品交易场景，提供商品发布与检索、收藏、留言咨询、购买意向及求购功能，并通过管理员后台维护商品、账号与互动记录。

主要实现：

- 设计用户、商品、收藏、订单、求购、留言和举报等7张数据表，完成注册登录、商品发布编辑及上下架等功能，使用 BCrypt 存储和校验密码。
- 使用 MyBatis 动态 SQL 实现关键词、分类、成色及价格区间筛选，支持价格和热度排序；为13个列表接口提供数据库分页，复用过滤条件保持记录查询与总数查询一致。
- 实现商品咨询与卖家回复、购买意向创建及取消、求购发布与审核，并提供管理员对用户、商品、订单、留言和举报的管理页面。
- 实现本地图片上传、预览和移除，支持 JPG、PNG、WEBP；后端检查文件大小、类型及内容特征，采用 UUID 文件名保存，单张限制5MB。
- 使用 Spring Boot Test、JUnit 和 MockMvc 验证登录、分页、求购、留言及上传流程，11项自动化测试通过；将前端构建资源与后端集成为可执行 JAR，提供启动脚本及数据库资料。
